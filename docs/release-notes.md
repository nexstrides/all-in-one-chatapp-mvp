# v0.1.0 — Desktop MVP review build

Six presets, custom HTTPS accounts, isolated persistent Chromium profiles, sidebar,
title-based unread counts, tray lifecycle, per-user autostart, external links,
notifications, app DND/bypass, sticky alerts, reminders, metadata-only history,
idle hibernation and cache controls.

This is an unsigned review build. Real service logins, Windows toasts and lifecycle
must pass docs/windows-smoke-test.md before a public release. Provider compatibility
and notification delivery are not guaranteed.

Deferred: automatic updates, code signing, custom sounds, DOM unread recipes, calling,
downloads, cloud accounts, payments, analytics and admin portal.
